git branch: list branches, the * shows where I am
git switch -c feature/x: create a branch and move to it
git switch main: move to an existing branch
git merge feature/x: bring feature/x into the branch I am on
git branch -d feature/x: delete a branch that was merged
git log --oneline --graph --all: show all branches as a graph
git push: upload my commits to GitHub
git fetch: download new commits without touching my files
git pull: fetch, then merge into my branch
git clone <url>: copy the whole repository once
