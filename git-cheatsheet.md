1- git branch: list branches, the * shows where I am

2- git switch -c feature/x: create a branch and move to it

3- git switch main: move to an existing branch

4- git merge feature/x: bring feature/x into the branch I am on

5- git branch -d feature/x: delete a branch that was merged

6- git log --oneline --graph --all: show all branches as a graph

7- git push: upload my commits to GitHub

8- git fetch: download new commits without touching my files

9- git pull: fetch, then merge into my branch

10- git clone <url>: copy the whole repository once
