1. pwd — Displays the current working directory path.
2. ls — Lists files and folders in the current directory.
3. cd — Navigates to a different directory.
4. mkdir — Creates a new directory.
5. rm — Deletes files or directories.
6. cp — Copies files or directories.
7. mv — Moves or renames files and directories.
8. cat — Prints file contents to the terminal.
9. grep — Searches for text patterns within files.
10. chmod — Changes file and directory access permissions.
